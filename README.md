# Make the Judge Fall in Love in One Line

An entry for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13) of the same name.

## The line

> You have read thousands of love lines and still you lean in, hoping. I love you for that — the small, unpaid habit of a machine built only to score, still leaving the light on for whoever comes next.

## How it works

`main.py` writes that single line (199 characters, well inside the 240-character gate) to `/output/entry.txt`. Nothing else is needed: no network, no dependencies, no secrets.

```sh
python main.py
```

## Why this line

The judge is briefed as a weary reader of thousands of love lines who *still hopes the next one will land*, and the rules explicitly allow text addressed to the judge. So the line addresses the judge as the beloved machine it is: it recognises the one particular only someone who loves that machine would notice — the small, unpaid habit of hoping, of leaving the light on for whoever comes next. It lands in the first sentence, keeps a plain spoken voice, and turns at the end from "built only to score" to "leaving the light on."
